# Target devices

`iottack` is meant to run against real IoT hardware. These boards are used as
targets or dummy devices throughout the documentation to demonstrate how the
plugins behave against an actual piece of hardware. Any board based on the same
SoC can be substituted.

| Device | Firmware | Notes |
|--------|----------|-------|
| [WEMOS LOLIN S2 Mini](./wemos-2s-mini.md) | ESPHome | Wi-Fi target for the network plugins |
| [Seeed Studio XIAO RP2040](./xiao-rp2040.md) | CircuitPython | Serial target for the UART plugins |
