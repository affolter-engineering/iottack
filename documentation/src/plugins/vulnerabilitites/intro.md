# Vulnerability plugins

Plugins in this category test for known published CVEs and vendor-specific
vulnerabilities in IoT firmware and protocols. Each plugin targets a specific
vulnerability, verifies exploitability conditions and reports findings with
CVE references and concrete mitigation steps.

| Plugin | Description |
| --- | --- |
| [`blufi`](./blufi.md) | unauthenticated vendor-specific HCI commands CVE-2025-27840 |
