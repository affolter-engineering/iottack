# nRF52840 Dongle

The Nordic Semiconductor nRF52840 USB dongle, running the
[nRF Sniffer for 802.15.4](https://github.com/NordicSemiconductor/nRF-Sniffer-for-802.15.4)
firmware, is used by the `zigbee sniffer` and `zigbee capture` plugins as a
passive IEEE 802.15.4 receiver.

## USB identifiers

All variants share vendor ID `0x1915` (Nordic Semiconductor ASA). `iottack`
auto-detects the dongle by VID/PID via Linux sysfs. Use `--port` to override
when multiple dongles are connected.

| PID | Mode |
| --- | --- |
| `0x520F` | Application (sniffer) mode |
| `0xCA37` | DFU bootloader mode |
| `0x154A` | nRF52 USB Product (generic) |
| `0x154B` | nRF Sniffer for 802.15.4 official firmware |

## Flashing the firmware

Download the pre-built firmware package from the
[nRF Sniffer for 802.15.4 releases](https://github.com/NordicSemiconductor/nRF-Sniffer-for-802.15.4/releases)
page and follow Nordic's flashing guide. The dongle ships in bootloader mode
(PID `0xCA37`). After flashing it switches to application mode (PID `0x520F`
or `0x154B`).

## Linux setup

The dongle uses USB CDC-ACM and appears as `/dev/ttyACM*` without additional
drivers. Grant unprivileged access by adding the user to the `dialout` group:

```sh
sudo usermod -aG dialout $USER
```

Log out and back in for the change to take effect. Alternatively, install a
udev rule so any user can open the device:

```sh
echo 'SUBSYSTEM=="tty", ATTRS{idVendor}=="1915", MODE="0666"' \
  | sudo tee /etc/udev/rules.d/99-nrf52840.rules
sudo udevadm control --reload
sudo udevadm trigger
```
